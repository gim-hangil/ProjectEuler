# Project Euler Solution

This repository contains solutions to problems from [Project Euler](https://projecteuler.net/).

## File Name Format

There are two files for each problem:
1. `000.ProblemName.c`: The first code I wrote to solve the problem.
2. `000.ProblemNameImproved.c`: The improved version of the code.

## `run.sh`

You can use the `run.sh` script to run the code for a specific problem.

```sh
❯ ./run.sh -h
Usage: ./run.sh -n <problem_number>

❯ ./run.sh -n 1
Compiling ./001.MultiplesOfThreeOrFive.c...
Executing ./001.MultiplesOfThreeOrFive...
233168
Removing ./001.MultiplesOfThreeOrFive...
```
